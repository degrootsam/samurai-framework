## Design notes and plans

Specs in [`superpowers/specs/`](superpowers/specs) record the design at the time a feature was built; the guides above describe what the code does now. When they disagree, the guide wins. Plans in [`superpowers/plans/`](superpowers/plans) are the step lists the features were built from:
